# htgame 现状审计

审计日期：2026-10-22。范围仅为 `htgame`，不包含旁边的 `OpusMC` 和 `Webgame`。

## 结论与证据范围

这是一个有实际玩法、值得继续演进的 WebGL2 单人 Minecraft 风格原型，已经超出单纯的体素展示。当前主要差距是规则准确性、存档可靠性、现代世界数据结构和完整生存进程，不能仅靠新增纹理/方块条目达到原版 1.20+。

用户已上机确认：游戏进入退出、物品合成、挖掘放置、生物互动、红石、结构生成和附魔等基础功能可用。本方案以此为基础，不再重复验证基础运行流程。

代码审计覆盖 15 个非资源 JavaScript 文件、注册表统计、材质 ZIP 与构建管线；对特定物品/保存边界问题做过最小方法级复现。基础功能能用与边界条件存在缺陷并不矛盾。下文区分已有实现、近似实现、缺失系统与确认问题，不编造总体完成百分比。

本轮交付为文档，不修改游戏源代码。后续章节中的测试是未来开发的验收设计，不表示这些新增功能已经实现或通过验收。

## 引擎边界

- 实际使用 `16×16×256` 区块柱和 `16³` 网格段，block/meta/light 各为 Uint8。光照天空/方块各占 4 bit，包含 BFS 传播与网格 AO。
- 存在 20 TPS 和渲染插值，但每帧最多补 5 tick，长帧时间截断为 250ms，补满后丢积压（`game.js:618–636`）。这是负载保护取舍，不是后台准确推进。
- `updateChunks(6)` 不能保证 6ms 上限：一个完整区块生成/照明或多个脏段网格仍同步运行（`game.js:773–838`）。没有 Worker。
- 按段进行视锥剔除和透明倒序；透明段内部没有逐面排序。没有通用 greedy meshing（`mesher.js:111–182`，`render.js:628–660`）。
- 全部修改区块加载到 `savedChunks`，不是按需磁盘缓存；长期探索和建造会扩大内存占用（`save.js:68`，`game.js:818`）。
- 只改 HEIGHT 不足以支持 -64..319：区段 key 的乘 16、0xFFFF 脏段掩码、Y 索引和光照边界都要迁移（`game.js:829,860`）。
- 地形与结构使用种子 RNG；天气、AI 等仍有 Math.random，因此不能声称整个模拟可确定性重放。
- 未修改区块会由生成器重建，存档没有 generatorVersion。未来改生成器可能产生接缝或群系颜色漂移。
- 当前没有 package.json、自动测试体系和 Git 仓库。建议开发第一阶段建立这些基础，但本次仅提交文档。

## 指定材质包的实际情况

`Pixel Perfection Legacy 13.21.2.zip` 已经被 `tools/build_from_pack.py` 接入。内存执行构建器生成的内容与现有 `game/js/assets.js` 逐字节相同。

| ZIP 资产 | 数量 |
|---|---:|
| 文件总数 / PNG | 6,924 / 5,139 |
| 方块 / 物品 / 实体 / GUI PNG | 1,683 / 728 / 735 / 485 |
| 方块模型 / 物品模型 JSON | 839 / 37 |
| blockstates JSON | 172 |
| OGG | 355 |
| .mcmeta | 226 |

现用资源：412 个纹理键、457 帧层、118 张 GUI/实体/环境图。391 个纹理键来自包，20 个来自 `assets.vanilla.js`，1 个是白色辅助纹理；118 张图中 114 来自包，4 个 fallback。不能称全部素材都已改成包内素材。

20 个纹理 fallback 是床面、刷怪蛋与树叶粒子；床与蛋可用包内实体纹理、通用纹理及染色生成，无需手绘。4 张图片 fallback 是菜单背景、游戏内菜单背景、shadow、vignette。

资源包有模型、blockstates、动画、音频、发光/CTM/随机实体等配置，当前主要读取 PNG。专用构建器忽略动画 frametime、单帧 time、interpolate；shader 统一每两 tick 切帧。声音仍全部程序合成；包内 sounds.json 仅列 6 个替换事件，不能代表全部 355 音频的可用映射。

`pack.mcmeta` 声明 pack_format=28、supported_formats=28..32767，`pack.txt` 又写 1.13–1.20.2；overlay 内容不完整。应按固定玩法版本做引用与覆盖校验，不能用 ZIP 文件名推断精确兼容版本。

当前 texture array 固定16像素、457层，未检查硬件层数上限；全量导入前必须分组与查询 GPU 能力。模型视觉不应代替碰撞/掉落等玩法定义。
